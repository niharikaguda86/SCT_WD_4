# SkillCraft Technology – Web Development Internship
## Task 04: To-Do List Web Application

---

A simple and responsive To-Do List Web Application that helps users organize tasks efficiently. Users can add, update, mark, and delete tasks in real time through an intuitive interface.

---

### 📌 Features

➕ Add new tasks

✏️ Edit existing tasks

✅ Mark tasks as completed

🗑️ Delete tasks

📱 Responsive design for all devices

💾 Data persistence using browser storage (LocalStorage)

---

### 🛠️ Technologies Used

HTML5 – Structure of the application

CSS3 – Styling and responsive layout

JavaScript (ES6) – Task management logic and DOM manipulation

---

### 🎯 Application Workflow

Enter a task in the input field

Click Add to include it in the list

Mark tasks as completed when finished

Edit or delete tasks as needed

---

### 🌟 Future Enhancements

Task categories and priorities

Due dates and reminders

User authentication

Cloud-based storage

Dark mode support
